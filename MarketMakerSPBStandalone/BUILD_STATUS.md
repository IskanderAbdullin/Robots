# MarketMakerSPBStandalone — build verification

Generated by project development (2026-11-20).

## What the CI proves
- .NET 10 Release builds of core strategy, the T-Invest SDK adapter, headless host and paper demo.
- Fake-broker tests for post, cancel acceptance vs terminal confirmation, recovery, foreign-order blocking, trade deduplication.
- Pure paper tests: repricing barriers, fresh-book/account gates, durable restarts, 20,000 seeded random book configurations, inventory reservations and P&L ledger replay.
- Windows WPF GUI compiles on `windows-latest`. GUI release uses `[gui-release]` commit message.

## What the CI does *not* prove
- Real T-Invest credentials, any actual exchange stream's timing/quality, brokerage portfolio permissions or exchange schedules.
- Orders API actual rate-limit and failure/error quotas, end-to-end live latency, fills under SPB pro-rata.
- Exact economic output or behavioral parity versus the original OsEngine robot.
- Windows installation/usefulness, network disconnect and disk failure behavior.
- Profitability, commissions or any safety guarantee on live money.

## Release policy
This is a **development preview**, and defaults to read-only. Do not activate real money. No API secrets or example credentials are bundled. A GUI artifact is created only on an explicitly marked release commit.
